# Ughrani (ઉઘરાણી / उघराणी) 📒💼

A lightweight, high-performance digital ledger (Khata) app designed for local shopkeepers and small retail merchants to track customer dues, credit ("udhar"), payments received ("jama"), and daily cashflow with ease.

## ✨ Key Features (Planned)
- **Customer Ledger (Khata)**: Maintain individual accounts for each customer with one-click credit/debit entries.
- **Dues Summary**: Instant overview of total money to collect ("Ughrani") and total money settled.
- **WhatsApp / SMS Reminders**: One-tap friendly reminder messages to customers with outstanding balances.
- **Multi-Device / Web Access**: Responsive web interface (PWA) with fast offline-first capabilities.
- **Export & Reports**: Daily/Monthly ledger statements in PDF/Excel format.
